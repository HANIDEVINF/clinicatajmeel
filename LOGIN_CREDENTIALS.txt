## TROUBLESHOOTING "MongoDB is not available":

This error appears because Flask needs to be restarted properly.

**Quick Fix:**
1. Stop Flask (Ctrl+C in the terminal running it)
2. Restart with:
   ```bash
   cd C:\Users\HANI\Desktop\freelance\tajmeelclinic\backend
   .\venv\Scripts\python.exe app.py
   ```
3. Wait for: "[OK] Connecte avec succes a MongoDB"
4. Then refresh your browser
